死亡回溯 DeathRewind

逃离鸭科夫的终极救星。
死过一次？没关系。
回到 60 秒前的那个节点，重整旗鼓。

立即安装 配置指南

核心特性

死亡回溯

死亡时在原生结算界面获得一次回溯机会，回到约 60 秒前的位置。

时间轴节点

结算界面时间轴提供 60 / 50 / 40 / 30 秒四个节点，默认选中 60 秒（最老节点）。节点标签只标秒数，跨空间时回溯按钮会补上空间名。

跨空间回溯

神秘山洞、仓库区地道等独立空间内也能回溯，还能跨空间回到主地图的老位置。

1UP 提示

HUD Buffs 状态栏首位显示硬币形状「1up」图标，提示你还有一次机会；用掉后隐藏，关卡重置后恢复。进关拿到机会的那一刻还会响一次「1UP」提示音（每关一次，可关闭或调音量）。

设置面板（Ctrl+N）

游戏内按 Ctrl+N 打开：显示当前得分、1UP 存量（用掉的画删除线）与冷却倒计时；可开启「增强模式」，并调「每关 1UP 上限（1~3）」与「复活冷却（30/60/90 秒）」，改完立即生效并写回 config.txt。增强模式默认关闭，关闭时保持原样（每关一次复活）。

击杀积分换 1UP（增强模式）

增强模式开启后：**自己击杀** BOSS 得 50 分、普通生物得 5 分，累计 100 分额外获得一次复活机会（带音效），分数清零重新累计；分数每关重算。环境、陷阱、爆炸等非玩家击杀不计分（判定方式与游戏任务计数一致）。

世界默认不回滚

默认 position 模式只回玩家位置、朝向、血量；敌人、箱子、爆炸桶不跟着回滚。想要完整世界回滚可切到 full。

换地图才清空

在独立空间之间切换不会清空锚点，换地图（换关卡）才清空重来。

怎么使用

  1. 1. 遭遇死亡

    在战斗中阵亡，游戏会弹出原生的 YOU DIED 结算界面。

  2. 2. 选择回溯节点

    原生「继续」按钮下方会多出一个回溯按钮，旁边是回溯时间轴。按下或拖动时间轴会吸附到最近的节点（60 / 50 / 40 / 30 秒），默认选中 60 秒前那个最老的节点；选中节点时预览画面与实际回溯目标同步切换。

  3. 3. 确认回溯

    点击回溯按钮即在所选节点复活；点原生「继续」则接受这次死亡。机会用掉后再次死亡就没有回溯按钮了（除非开启 autoRewind）。

  4. 4. 继续战斗

    带着旧的位置与朝向回来，血量回到锚点时刻的血量（不低于最大血量的一半）。HUD 上的「1up」硬币会同时消失，本关不再有第二次机会。

安装

方式一：Steam 创意工坊（推荐）

在 Steam 创意工坊搜索「死亡回溯 / DeathRewind」订阅即可（File ID: 3823953866）。 游戏自带原生 Mod 加载器，订阅后重启游戏即生效，无需手动放置文件。

方式二：手动安装

把下列文件放进游戏目录的 Mods 文件夹下（每个 Mod 一个子目录）：

Duckov.app/Contents/Mods/DeathRewind/

  • DeathRewind.dll —— Mod 主程序集
  • info.ini —— Mod 元信息（名称、版本、标签）
  • 0Harmony.dll —— Harmony 2.x 运行库
  • preview.png —— 预览图（可选）

要求：游戏为支持原生 Mod 加载的版本，Harmony 2.x。Mod 以 net472 为目标框架，Unity Mono 运行时。

还原了什么？

状态类型 position（默认） full
玩家位置 ✓ 还原 ✓ 还原
玩家朝向 ✓ 还原 ✓ 还原
玩家血量 ✓ 还原 ✓ 还原
玩家背包 / 装备槽 ✗ 不还原 ✓ 还原
敌人位置与血量 ✗ 不回滚 ✓ 还原
Boss（零号区·矮鸭等） ✗ 不回滚 保留原地，不会消失
容器 / 战利品箱内容 ✗ 不回滚 ✓ 还原
门 / 世界时间 ✗ 不回滚 ✓ 还原
爆炸桶等可破坏物 ✗ 不回滚 ✗ 不回滚（炸毁状态保持）

默认的 position 模式只动你自己；full 模式才会连世界一起回滚，代价是每个锚点都多存一份主存档副本（约 1.3MB）。

常见问题 (FAQ)

时间轴节点数与实际可回溯目标不一致怎么办？
时间轴上的节点数取决于当前关卡里实际攒下的锚点，可能少于四个。当前空间找不到匹配节点时，会用本关卡其它空间的锚点补位（跨空间时回溯按钮会标注空间名）。
换地图（进新关卡）后锚点会清空吗？
是的。换地图（进入新关卡）会清空所有锚点，不能跨关卡回溯。锚点只在当前关卡内有效；但在神秘山洞、仓库区地道这类独立空间之间切换不会清空。
回溯只还原玩家自身状态吗？
默认的 position 模式是。回溯只还原玩家位置、朝向、血量；世界里的敌人、箱子、已经炸掉的爆炸桶不跟着回滚。想连世界一起回滚可改用 rewindScope=full。
开启 rewindScope=full 有什么影响？
完整世界回滚会增加存档负担：每个锚点都会存一份主存档副本，约 1.3MB/锚点。请谨慎设置 anchorCapacity，避免存档过大。
进图时间不足 60 秒会回溯到哪？
会回到你进图那一刻的位置。锚点是从进入场景开始记录的，所以时间不够时，最早的可用锚点就是入图点。
快捷键是什么？
F9 回溯、Escape 接受死亡。这两个热键用于原生结算界面不可用时的 IMGUI 降级面板。
